# Class Homework (shared)

A shared homework list for classmates, made by Stu. Open the page at https://aquarius4310.github.io/Homework-Shared/

- `index.html` is the page. Each person's picks, checkmarks and own items save in their own browser.
- `grab.js` is what the **Get homework** bookmark runs on Schoology. It only reads.
- `data/classes.json` is the shared list. Only the owner can edit this repo. Friends send updates as comments on the **Updates** issue, and `sync_shared.py` (GitHub Action) applies them with rules.
- `friends.json` lists the GitHub usernames allowed to send updates.
